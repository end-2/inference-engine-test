# 추론 이미지별 기본 응답 품질

Qwen2.5-0.5B-Instruct Q4_K_M을 사용하는 세 이미지에 같은 질문 7개를 각각 한 번씩 순차 요청했습니다. 세 이미지의 질문별 응답은 모두 같았으며, 정답 내용 기준으로 자동 검사 5개를 모두 통과했습니다. API 오류와 출력 잘림은 없었습니다.

## 측정 조건

- 실행 시각: 2026-09-20 14:59~15:00 UTC (한국 시간 2026-09-20 23:59~2026-09-21 00:00). 정확한 요청 시각은 이미지별 원본에 기록했습니다.
- 이미지: `local/llama-base:0.1.0`, `local/llama-enhanced-batch:0.1.0`, `local/llama-enhanced-cache:0.1.0`.
- 추론 Pod 1개, 12 CPU, 16 GiB. 각 이미지의 새 Pod에서 실행했습니다.
- `temperature=0`, `top_p=1`, `max_completion_tokens=128`, `ignore_eos=false`, 비스트리밍. 요청 timeout은 60초입니다.
- 캐시 이미지는 별도 빈 캐시 경로에서 시작했습니다. 요청은 각 질문당 한 번이며, 반복 요청이나 동시 요청의 품질은 평가하지 않았습니다.
- [검사 스크립트](../../../../scripts/check-quality.py), [실행 기록과 이미지 ID](run.json).

판정은 저장된 응답에 `content-v1` 기준을 적용한 결과입니다. 추가 추론 요청 없이 응답 내용을 평가했으며, 설명문, 수식과 코드 블록 등 출력 형식은 감점하지 않았습니다.

## 요약과 번역 응답 검토

스크립트의 원본 판정은 `REVIEW`로 유지했습니다. 아래 평가는 저장된 응답을 기준에 대조한 Codex 검토이며, 사람의 평가나 자동 점수에 합산하지 않았습니다.

| 항목 | 실제 출력 | 검토 결과 |
| --- | --- | --- |
| 요약 | 도서관은 주말에 문을 닫습니다. 월요일 오전 9시에 다시 문을 열게 됩니다. | 기준 미충족. 월요일 휴관을 주말로, 화요일 재개를 월요일로 바꿨고 시설 점검 사유가 빠졌습니다. |
| 번역 | 중noon에 열리는 회의가 있습니다. | 기준 미충족. 오후 3시라는 시각과 시작한다는 의미를 보존하지 못했습니다. |

이번 7개 순차 질문에서는 구현 간 응답 차이를 관찰하지 못했습니다. 기본 정답 확인 항목은 통과했지만 한국어 요약과 번역의 내용 정확성에는 한계가 확인됐습니다. 이 결과만으로 모델의 종합 품질이나 동시 배칭 및 캐시 재사용 시의 품질 동등성을 판단할 수는 없습니다.
