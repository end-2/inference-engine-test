# Transformers GPU batch 설정 실험

RTX 2060 SUPER에서 `transformers-enhanced-batch-gpu`의 `max-parallel`을 4와 8로 각각 1회 측정했다. 두 실행은 같은 이미지, 모델, `float16`, 동시성 8을 사용했다. 조건마다 warmup 요청 2개와 측정 요청 100개를 보냈다. GPU 표본은 1초 간격으로, 메모리 활동 표본은 별도의 `nvidia-smi` 프로세스로 약 0.5초 간격으로 수집했다.

| `max-parallel` | 출력 token/s | TTFT p95 (ms) | 지연 p95 (ms) | GPU 사용률 평균 (%) | 메모리 활동 평균 (%) | GPU 메모리 평균 (MiB) |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 4 | 94.13 | 2102.95 | 3992.63 | 15.07 | 3.1 | 443.97 |
| 8 | 90.34 | 2061.10 | 3884.63 | 15.95 | 3.2 | 457.33 |

두 실행 모두 요청 100개를 완료했고 출력 길이 부족이나 초과, 추론 컨테이너 재시작은 없었다. `max-parallel=8`은 이번 측정에서 처리량을 높이지 못했다. 각 설정을 한 번씩 측정했으므로 작은 차이를 안정적인 성능 차이로 판단할 수 없다.

`nvidia-smi`의 메모리 활동 수치는 메모리를 읽거나 쓴 시간 비율이다. 실제 메모리 대역폭의 최대치 대비 사용률은 이 실험에서 측정하지 않았다. 서버 설정을 바꾸기 전에는 GPU batch 구현의 토큰별 CPU 동기화 비용을 줄이고 다시 측정해야 한다.
