# Transformers GPU 배치 최적화 측정

RTX 2060 SUPER에서 `transformers-enhanced-batch-gpu`를 측정했다. 모델은 `HuggingFaceTB/SmolLM2-135M-Instruct`, dtype은 `float16`이다. AIPerf는 `temperature=0`, `ignore_eos=true` 요청으로 동시성 `1,2,4,8`을 실행했다. 각 조건에는 warmup 요청 2개와 측정 요청 100개를 사용했다. 서버 설정은 `max-parallel=4`, `batch-wait-ms=5`, `n-ctx=1024`였다.

GPU 전용 배치 구현은 같은 배치의 토큰을 함께 샘플링하고 decode 연산에 CUDA Graph를 재사용한다. 이 경로는 위의 결정적 샘플링 조건에서 동작한다. 다른 요청 옵션은 일반 GPU 배치 경로를 사용한다. 측정 이미지는 `local/transformers-enhanced-batch-gpu:0.1.1`이며 이미지 ID는 `sha256:b1f8d114f368946e4c7da1fe85da215870f484527c906ef3fd0bc36f5fe76fe8`이다.

네 조건 모두 요청 100개를 완료했다. 요청별 출력 길이 부족과 초과는 0건이며 추론 Pod와 AIPerf 컨테이너의 재시작도 없었다. 조건별 GPU 표본은 각각 45, 37, 32, 32개다. 메모리 활동은 별도의 호스트 `nvidia-smi`에서 약 0.5초 간격으로 수집했다.

같은 GPU와 동시성 8에서 [이전 배치 설정 측정](batch-config-tuning-20260928.md)의 `max-parallel=4`는 94.13 token/s, GPU 평균 사용률 15.07%였다. 새 구현은 313.32 token/s, 35.22%였다. 각 결과는 1회 측정이다.

새 구현의 `max-parallel=8`도 동시성 8에서 1회 측정했다. 처리량은 331.85 token/s였지만 GPU 평균 사용률은 33.63%, GPU 메모리 평균은 904.80 MiB, 지연 p95는 1331.30 ms였다. 기본값 4는 이 측정에서 사용률과 지연, 메모리 사용량의 균형이 더 좋았다. 작은 처리량 차이는 반복 측정 없이는 확정할 수 없다.

`nvidia-smi`의 메모리 활동은 메모리를 읽거나 쓴 시간의 비율이며 실제 전송량이나 최대 메모리 대역폭 대비 비율이 아니다. 이 측정으로 메모리 대역폭 포화 여부는 판단할 수 없다.
