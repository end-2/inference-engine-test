# TTFT와 TPOT를 분리한 goodput

한 지표의 임계값만 적용하며 다른 지표는 제한하지 않습니다. Goodput은 통과 요청 수를 전체 측정 관찰 시간으로 나눈 값입니다. 각 반복의 goodput을 산술 평균하며 워밍업은 제외합니다. TPOT는 요청별 평균이고 개별 토큰 ITL 상한이 아닙니다.

![지표별 goodput](goodput-separated.png)
